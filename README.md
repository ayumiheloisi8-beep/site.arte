# Arte na Escola

Site escolar simples sobre Artes, feito com HTML, CSS e Bootstrap.

## Páginas
- Início
- Sobre
- Conteúdos
- Exercícios

## Paleta de cores
- Amarelo manteiga: #F6E7A1
- Lilás: #E9E1F0
- Azul acinzentado: #6688A8
- Verde sálvia: #A8B8A0

Abra o arquivo `index.html` no navegador. Mantenha a pasta `css` junto com os arquivos HTML para que as cores e estilos apareçam corretamente. As imagens, vídeos e links externos precisam de internet.

O questionário da página Exercícios mostra a quantidade de respostas corretas. O estilo visual fica em `css/estilo.css` e o funcionamento do questionário em `js/script.js`.
